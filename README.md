# Thin Lei Sandi Portfolio

Build me a modern personal portfolio website for a Computer Science student who is interested in Data Science, Machine Learning, and NLP.

Style direction:

- Clean, modern, professional, and slightly bold

- Dark theme with elegant gradients

- Strong typography, good spacing, and polished card-based layout

- Mobile responsive and easy to navigate

- Avoid generic boring templates

- Use subtle motion and smooth hover effects

- Make it feel personal and impressive, not overdesigned

Website structure:

1. Hero section

- My name: Thin Lei Sandi

- Title: Computer Science Student | Data Science | Machine Learning

- Short intro about being a final-year CS student at Ton Duc Thang University

- Two buttons: View Projects and Contact Me

2. About section

- Short paragraph about my interest in data, ML, NLP, and solving real-world problems

- Mention that I like building useful projects and learning from practical work

3. Skills section

Include these grouped categories:

- Programming: Python, Java, C, JavaScript, HTML, CSS, SQL

- Data Science: Data Analysis, Data Visualization, Data Mining, Data Preprocessing

- Machine Learning: Supervised Learning, Unsupervised Learning, Model Evaluation

- Deep Learning: Neural Networks, RNN, LSTM, GRU

- Tools: Pandas, NumPy, Scikit-learn, PyTorch, Matplotlib, Seaborn, Streamlit, Figma, Balsamiq

- Soft Skills: Communication, Teamwork, Problem Solving, Critical Thinking, Adaptability

4. Projects section

Create visually nice project cards for these projects:

- IMDb Sentiment Analysis using RNN, LSTM, and GRU

- NLP Final Project

- Student Dropout Prevention - Early Warning System

- Data Storm Vietnam 2025 Datathon

- Massive Data Processing Project

- Software Engineering Project - UI/UX Design

For each project card, include:

- Project title

- Short description

- My role

- Tech stack

- Optional GitHub/demo button

5. Education section

- Ton Duc Thang University, Ho Chi Minh City, Vietnam

- Bachelor of Computer Science, Final Year Student

- GPA: 8.44/10.00

6. Certifications section

- Datathon Vietnam 2025 Participation

7. Contact section

- Email

- GitHub

- LinkedIn

- Resume download button

Design requirements:

- One-page scrolling layout

- Smooth anchor navigation

- Elegant section dividers

- Professional footer

- Good contrast and readability

- Make it look like a portfolio for someone applying to internships and entry-level data science or machine learning roles

Content tone:

- Confident but humble

- Clear and concise

- Professional and student-friendly

Important:

- Use realistic placeholder links for GitHub, LinkedIn, and email

- Make the layout visually strong and modern

- Use icons only where helpful

- Keep everything editable
